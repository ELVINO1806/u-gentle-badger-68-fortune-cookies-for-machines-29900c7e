This program writes my one-line fortune-cookie entry for the [Fortune Cookies for Machines](https://make.fun/bounty/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e) competition on make.fun to `/output/entry.txt`.

## How to run

```sh
python3 main.py
```

The entry is written to `/output/entry.txt`. The program uses only the Python standard library and needs no network access.
